# Cross-linguistic Rhythm Formant Analysis of Assamese and Mising conversational speech

This repository contains the code used in two related research works on rhythm analysis in spontaneous speech of Assamese and Mising, two low-resourced languages from Assam, North-East India.

## Papers

1. Gogoi, Parismita, Priyankoo Sarmah, and S. R. M. Prasanna. **"Cross-linguistic rhythm analysis of Mising and Assamese."** ACM Transactions on Asian and Low-Resource Language Information Processing 23.10 (2024): 1-18.

2. Gogoi, Parismita, Priyankoo Sarmah, and S. R. M. Prasanna. **"Analyzing long-term rhythm variations in Mising and Assamese using frequency domain correlates,”** International Journal of Asian Language Processing, 2025. [Online]. Available: https://doi.org/10.1142/S2717554525500018
